# לוח עתים לבינה — תשפ״ו

## פתיחה ב-Android Studio

1. **File → Open** → בחר תיקיית `luach_itim`
2. בתחתית המסך תופיע הודעה:
   > *"Gradle wrapper jar missing. Download it?"* → לחץ **Download**
3. המתן לסנכרון (~2 דקות)

---

## סנכרון עם יומן הטלפון

האפליקציה מוגדרת ב-`AndroidManifest.xml` כאפליקציית לוח שנה/יומן (`android.intent.category.APP_CALENDAR` + `android:appCategory="productivity"`), כך שהמערכת (לוחצ׳רים, קיבוץ אפליקציות וכו׳) מזהה אותה ככזו.

אירועי היומן האישי (Diary) מסתנכרנים **אוטומטית** ליומן המובנה של הטלפון (Google Calendar / Samsung Calendar / כל יומן שמותקן) - הוספה, עריכה ומחיקה - בלי צורך לסמן משהו ידנית בכל פעם. הסנכרון:

- כתוב ל"יומן מקומי" (`ACCOUNT_TYPE_LOCAL`) בתוך ה-Calendar Provider של אנדרואיד - בדיוק אותו מנגנון שכל אפליקציית יומן קוראת ממנו.
- **לא דורש חיבור לאינטרנט בשום שלב** - לא בסנכרון עצמו, לא בבקשת ההרשאה (זהו דיאלוג מערכת מקומי בלבד), ולא בהפעלה הראשונה. האפליקציה כלל לא מבקשת הרשאת `INTERNET` ב-manifest, כך שאין לה אפשרות טכנית לגשת לרשת.
- ניתן לכבות אותו בהגדרות ("סנכרון ליומן הטלפון").
- בכל פתיחה של מסך היומן, אירועים ישנים שטרם סונכרנו (למשל מגרסה קודמת של האפליקציה) מתעדכנים אוטומטית גם הם, ברקע.

## עדכון local.properties

פתח את הקובץ `local.properties` ושנה את השורה:
```
sdk.dir=C\:\\Users\\USER\\AppData\\Local\\Android\\Sdk
```
לנתיב האמיתי שלך. לרוב:
```
sdk.dir=C\:\\Users\\<שם המשתמש>\\AppData\\Local\\Android\\Sdk
```
